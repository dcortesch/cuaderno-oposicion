# Explorador del sistema de preparación de oposiciones

Versión 1.0 - 6 de agosto de 2026

## Qué contiene

- Panel operativo de inicio.
- Buscador global.
- Plan de nueve meses, diferenciando el plan Ballesteros de la ruta personal.
- Catálogo filtrable de temas.
- Espacio de trabajo genérico por tema y ficha completa del T04.
- Explorador de los ocho problemas núcleo del T04.
- Técnicas, vídeos y recursos del sistema de tres niveles.
- Seguimiento local de problemas, repasos, notas y programación.
- Biblioteca de documentos maestros y archivos T04.

## Progreso personal

Las marcas de problemas, repasos, vídeos y programación se guardan en `localStorage` del navegador. No se publican en GitHub ni se sincronizan entre dispositivos. En `Repasos y evidencias` se pueden exportar e importar como JSON.

## Publicación

El sitio utiliza rutas relativas y funciona directamente en GitHub Pages. Para probarlo localmente, ejecuta `PREVIEW_LOCAL.bat` en Windows o `./preview-local.sh` en macOS/Linux y abre `http://localhost:8000`.

## Integridad del contenido

- Los datos del plan reproducen la información memorizada en el proyecto OPOSICIONES.
- Los problemas visibles usan el campo `Enunciado resumido` de la matriz T04.P03. No se presentan como enunciados literales.
- Las técnicas, vídeos y repasos proceden del sistema T04.P03 generado el 6 de agosto de 2026.
- Los temas distintos de T04 aparecen como mapa del itinerario y no implican que exista material elaborado.
